# Seguridad en el flujo ✅

← [[15 §Deuda técnica]] · [[15 Flujo de trabajo y calidad|↑ 15]] · [[15 §Trabajo con IA]] →

- Ningún secreto, clave de firma ni contraseña en el repositorio (`.gitignore` y revisión).
- Acciones de GitHub fijadas por versión y, más adelante, por hash (tarea [[F1-35 Acciones de GitHub fijadas por hash y Dependabot|F1-35]]).
- Dependencias pocas, con versión fija y licencia revisada.
