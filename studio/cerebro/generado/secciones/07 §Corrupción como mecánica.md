# Corrupción como mecánica ✅

← [[07 §Facciones]] · [[07 Sociedad, poder y eventos|↑ 07]] · [[07 §Estatus y clase social]] →

- El jugador **elige cuánto se mancha las manos** — no es obligatorio jugar sucio.
- Opciones: pagar o no la "protección", sobornar para obtener licencias, comprar en mercado negro, entregar información a una facción.
- Cada elección tiene beneficios y riesgos (inspecciones, multas, represalias).
- Quien juega limpio avanza más lento pero más seguro; quien juega sucio crece algo más rápido (el mercado negro aporta ≈ +7 %) y abusar pierde por las redadas ([[28 Números base de la economía|28]], sección 10). Los sobornos cuestan más cada vez y no hay medidor de corrupción ([[03 Comercio y mercado|03]]). El mercado negro es un complemento moderado, no una estrategia dominante.
